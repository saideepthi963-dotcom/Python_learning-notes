# Python Learning Notes 🐍

A collection of beginner-friendly Python notes, code examples, and practice exercises organized by topic.

This repository documents my journey of learning Python fundamentals and building a strong foundation for Data Engineering.

## 📚 Topics Covered

| Folder | Topics |
|---|---|
| `00_cheatsheets` | Python quick reference notes |
| `01_Python_Basics` | Variables, data types, expressions, operators |
| `02_Strings` | String basics, indexing, slicing, methods |
| `03_Numbers` | Math functions, rounding, random numbers, validation |
| `04_Conditionals` | if, elif, else, nested conditions, match-case |
| `05_Loops` | for loops, while loops, break, continue |
| `06_Lists` | Creating, accessing, modifying, sorting, copying, comprehensions |
| `07_Tuples` | Tuple basics, indexing, unpacking |
| `08_Sets` | Unique values, set operations |
| `09_Dictionaries` | Key-value pairs, methods, dictionary comprehensions |
| `10_Functions` | Functions, parameters, arguments, return values, lambda |
| `11_Exception_Handling` | try, except, else, finally |
| `12_File_Handling` | Reading, writing, and appending files |
| `13_Modules_and_Packages` | Imports, modules, packages |
| `14_JSON` | Reading, writing, and processing JSON |
| `15_CSV` | CSV reading and writing |
| `16_Dates_and_Time` | Dates, formatting, timedelta |
| `17_NumPy` | NumPy arrays, indexing, slicing, array operations, numerical functions |
| `18_Pandas` | Series, DataFrames, reading files, filtering, cleaning, grouping, aggregation, merging, joining |

## ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/saideepthi963-dotcom/Python_learning-notes.git
```

Navigate to the project folder:

```bash
cd Python_learning-notes
```

Run a Python file:

```bash
python 06_Lists/01_create_lists.py
```

Most examples use Python's standard library and do not require additional packages.
